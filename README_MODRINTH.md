## Description
LumynAPI is an API and library mod for all of most used code in projects by Lumynity Studios.
<br><br>
It contains such as e.g. many useful util classes (Entity, Ticking, Datagen etc),
config library and variable management (Both cross-loader and Fabric Data Attachments API since 1.20.4).<br>
It is cross-loader, and multi-version but only for loaders and versions we develop on.

## Developing with LumynAPI
LumynAPI has a wide documentation on how to set it up and how to work with it.<br>
